# Finance App – Releases

Dieses Repository enthält nur die fertigen, notarisierten Versionen der Finance App für macOS
und die Versionsliste (`appcast.xml`) für automatische Updates. Kein Quellcode, keine Daten.

Installation: neuestes Release öffnen, ZIP herunterladen, entpacken, „Finance App“ in den
Ordner „Programme“ ziehen und öffnen.
